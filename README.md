# gentle-shell-PR

A compact, read-only pull request sidebar for Gentle Shell and Pi.

> Work in progress. Installation and usage instructions will be finalized with the first verified release.

## Scope

- Show pull request status for the current GitHub repository.
- Render CI, review, and merge readiness without writing to GitHub.
- Use the active Gentle Shell/Pi theme.
- Avoid model calls and token consumption.
